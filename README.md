# Таблица → Текст

Автономное веб-приложение (PWA) на русском языке: преобразует каждую строку таблицы в связный текст по вашим шаблонам. Оптимизировано для iPhone, iPad и настольного браузера.

**Ничего устанавливать на сервере и собирать не нужно:** чистые HTML, CSS и JavaScript. Данные остаются на устройстве. Нет аналитики, аккаунтов и сетевых запросов к ИИ. Библиотека JSZip включена в проект локально и работает без сети.

## Возможности

- Вставка таблиц копированием из Excel, Apple Numbers или Google Таблиц.
- Импорт **XLSX, CSV, TSV, TXT** с автоматическим определением разделителя и поддержкой CSV-кавычек.
- Создание, копирование, удаление и автоматическое сохранение шаблонов.
- Подстановка данных по названиям столбцов, например `{Дата}` или `{Мероприятие}`.
- Специальные поля `{№}` (номер строки) и `{Количество}` (общее число записей).
- Вступление, шаблон строки или группы, заключение и необязательная нумерация.
- Объединение записей по **одному или двум выбранным столбцам**, настройки сохраняются внутри шаблона.
- Удаление повторов при перечислении значений через `{Поле|уникальные}`; перечисление всех — `{Поле|все}`, подсчёт разных — `{Поле|число}`.
- Переменные `{КоличествоВГруппе}` и `{КоличествоГрупп}` для итоговых сводок.
- Предпросмотр таблицы, предупреждения о отсутствующих столбцах.
- Копирование результата, отправка через системное меню iOS, экспорт TXT.
- Экспорт/импорт **резервной копии JSON** с таблицей и шаблонами.
- Работа **офлайн после первой успешной загрузки**, включая открытие с домашнего экрана.

> Важно: это локальный **шаблонизатор**, а не нейросеть. Он подставляет значения столбцов в подготовленный вами связный текст. Он не умеет самостоятельно перефразировать произвольный текст или изменять окончания слов по правилам грамматики. Для естественных согласований формулируйте шаблон под форму значений таблицы.

## Публикация в GitHub Pages

1. На GitHub создайте публичный репозиторий, например `tablica-v-tekst`.
2. Загрузите **содержимое этой папки** в корень репозитория: `index.html`, `app.js`, `styles.css`, `sw.js`, `xlsx-reader.js`, `manifest.webmanifest`, каталоги `icons/`, `vendor/` и остальные файлы. Не загружайте только ZIP без распаковки.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main`, папку `/(root)` и нажмите **Save**.
5. GitHub опубликует приложение по адресу вида `https://USERNAME.github.io/tablica-v-tekst/` (замените `USERNAME` и имя репозитория).
6. Откройте этот адрес с интернетом и дождитесь полной загрузки. После этого приложение сможет работать офлайн.

В проекте используются относительные пути (`./`), поэтому сайт подходит и для `username.github.io/repository/`, и для собственного домена.

## Установка на iPhone / iPad

1. Откройте опубликованный HTTPS-адрес в **Safari**.
2. Нажмите **Поделиться** (кнопка со стрелкой вверх) → **На экран «Домой» / Add to Home Screen**.
3. Если появится опция **«Открывать как веб-приложение»**, оставьте её включённой. Нажмите **Добавить**.
4. Откройте значок приложения с экрана «Домой», пока есть интернет; затем попробуйте открыть его в авиарежиме.

**Важно для iOS:** веб-приложение с домашнего экрана может иметь отдельное хранилище от вкладки Safari. Если вы работали в Safari и затем установили приложение, экспортируйте резервную копию из Safari и импортируйте её в установленное приложение.

## Как создать собственный шаблон

Допустим, таблица содержит столбцы `Дата`, `Мероприятие`, `Участники`:

```text
Дата        Мероприятие         Участники
12.11.2026 Конференция         15 человек
13.11.2026 Мастер-класс        20 человек
```

В поле **«Предложение для каждой строки»** укажите:

```text
{Дата} состоялось мероприятие «{Мероприятие}». В нём приняли участие {Участники}.
```

Результат:

```text
12.11.2026 состоялось мероприятие «Конференция». В нём приняли участие 15 человек.

13.11.2026 состоялось мероприятие «Мастер-класс». В нём приняли участие 20 человек.
```

Шаблоны сохраняются автоматически в локальном хранилище браузера.

## Сводные отчёты и объединение повторений

Например, исходная таблица:

```text
Место       Мероприятие
Библиотека  Лекция
Библиотека  Семинар
Библиотека  Лекция
Школа       Конкурс
```

Выберите в настройках шаблона **Главный столбец: Место** и текст:

```text
В {Место} состоялись мероприятия: {Мероприятие|уникальные}. Всего строк: {КоличествоВГруппе}.
```

Результат:

```text
В Библиотека состоялись мероприятия: Лекция и Семинар. Всего строк: 3.

В Школа состоялись мероприятия: Конкурс. Всего строк: 1.
```

Допустимые модификаторы:
- `{Поле}` или `{Поле|первое}` — первое непустое значение в группе;
- `{Поле|уникальные}` — разные непустые значения в порядке появления;
- `{Поле|все}` — все непустые значения, включая повторы;
- `{Поле|число}` — число разных непустых значений.

Для более точной группировки можно выбрать **дополнительный столбец**. Одинаковые сочетания двух значений собираются в один абзац. Приложение не меняет грамматические формы слов: шаблон должен учитывать написание исходных значений.

## Ограничения и хранение

- Excel `.xlsx` открывается **на устройстве**, без отправки таблицы на сервер. Берётся **первый видимый лист** книги, импортируются сохранённые значения ячеек, а не вычисляемые формулы; стили, изображения и объединение ячеек не воспроизводятся.
- Рекомендуемые размеры: Excel до **8 МБ** и **5000 строк на листе**, текстовые файлы до **4 МБ**.
- Все данные хранятся через `localStorage` на данном устройстве; очистка данных сайта, переустановка веб-приложения или ограничения хранилища iOS могут удалить их. Регулярно сохраняйте **резервную копию JSON** в приложении «Файлы».
- Для первой загрузки и обновления версии на GitHub Pages нужен интернет. После кэширования основных файлов через Service Worker ввод, генерация и экспорт работают без сети.
- Безопасный HTTPS обязателен для Service Worker (исключение: `localhost` при разработке).
- GitHub Pages размещает только код приложения. Таблицы и шаблоны на GitHub **не загружаются**.

## Локальный запуск на компьютере

Из папки проекта:

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000/`. Если открыть `index.html` двойным щелчком как `file://`, преобразование будет работать, но сервис-воркер для офлайн-режима не установится.

## Структура

```text
index.html             Интерфейс
styles.css             Стили для телефона, планшета, компьютера
app.js                 Парсер таблиц, шаблоны и хранение
sw.js                  Автономный кэш
manifest.webmanifest   Метаданные PWA
icons/                 Значки приложения
example.tsv            Пример данных
.nojekyll              Статический режим GitHub Pages
```

## Обновления

При изменениях приложения в GitHub полезно поменять версию кэша в `sw.js` (`CACHE_NAME`), чтобы установленная PWA загрузила новый набор файлов. Подключитесь к сети и повторно откройте приложение.

## Зависимости и лицензии

- Библиотека JSZip 3.10.1 для распаковки `.xlsx`: `vendor/jszip.min.js`; её лицензия — `vendor/JSZIP-LICENSE.md`. Используется локально, без CDN.
- Остальные компоненты приложения не зависят от серверной части.
